coDiagnostix

Surgery Planning Service

coDiagnostiX is an open software system. The library contains implant, abutment, and sleeve systems from several major implant manufacturers. Furthermore, the library includes the full portfolio of Straumann abutments that can be selected for the required indication with a specific abutment selection wizard. Direct data import from 3D CT/DVT scanning according to the widely accepted DICOM standard brings compatibility, and no case fee for external data processing is required.
